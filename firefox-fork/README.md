# פיירפוקס מסונן

בנייה של פיירפוקס לאנדרואיד (Fenix) מהקוד הפתוח של מוזילה, עם סינון התמונות של האפליקציה.

- `FIREFOX_REVISION` — הגרסה המדויקת של הקוד של פיירפוקס שבונים ממנה
- `mozconfig` — הגדרות הבנייה (arm64, רכיבי Gecko מוכנים)
- `apply.sh` — מחיל את השינויים שלנו על הקוד

הבנייה רצה ב-GitHub Actions (`.github/workflows/firefox.yml`) ומתפרסמת ב-release בשם `firefox-latest`.
הקוד של פיירפוקס ברישיון MPL 2.0.
